# Syna Karnani — Personal Website

A responsive static website with no dependencies or build step.

## Upload to GitHub
1. Extract this ZIP on your computer.
2. Create a GitHub repository.
3. Upload the extracted files and public folder to the repository root. Upload the contents, not the ZIP itself.
4. Commit the files.

## Deploy on Vercel
1. Create a new Vercel project and import your GitHub repository.
2. Use Framework Preset: Other.
3. Keep Root Directory at the repository root.
4. Leave Build Command empty. Output Directory is public, as configured in vercel.json.
5. Deploy.

No environment variables or package installation are needed.

## Edit the website
- public/index.html: text and links
- public/syna-karnani.jpg: homepage portrait
- public/style.css: colors, layout, typography
- public/syna-karnani-resume.pdf: linked resume

To preview locally, open public/index.html in your browser.

Vercel documentation: https://vercel.com/docs/builds
